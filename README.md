# ballistic

Эксперименты с GSL на примере внешней баллистики

* projectile.c - пример, навайбкоженный с помощью Qwen

Компиляция:

```make```

# Запуск с конфигом по умолчанию (projectile.conf)
./projectile

# Запуск с альтернативным конфигом
./projectile custom.conf

# Переопределить только начальную скорость
./projectile -v 120

# Переопределить скорость и угол, использовать другой конфиг
./projectile -v 120 -a 30 custom.conf

# Переопределить все начальные условия
./projectile -v 100 -a 40 -x 5 -y 2

# Показать справку
./projectile -h
