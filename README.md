# ballistic

Эксперименты с GSL на примере внешней баллистики

##

* projectile.c - пример, навайбкоженный с помощью Qwen
* k_over_m.awk - скрипт для вычисления баллистического коэффициента
* cannon.conf - конфигурация для выстрела из пушки ядром
* muscet.conf - конфигурация для выстрела из мушкета пулей (результат неточный - не учитывается сверхзвук)
* seed.conf - конфигурация для кидания "семенной бомбочки" из окна
* seed-small.conf

## Компиляция:

```make```

## Тестовый запуск

```make plot```

## Использование

### Запуск с конфигом по умолчанию (projectile.conf)
```./projectile```

### Запуск с альтернативным конфигом
```./projectile custom.conf```

### Переопределить только начальную скорость
```./projectile -v 120```

### Переопределить скорость и угол, использовать другой конфиг
```./projectile -v 120 -a 30 cannon.conf```

### Переопределить все начальные условия
```./projectile -v 100 -a 40 -x 5 -y 2```

### Показать справку
```./projectile -h```
